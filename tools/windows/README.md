# Проверочные скрипты для сервера 1С

Скрипты для разведки 1С через COM (`V83.COMConnector`) прямо на сервере
1С, под обычным пользователем Windows без прав администратора. Все пункты
меню, кроме установки команды `ai1c`, только читают — в базу ничего не
пишется.

## Запуск

Откройте **Windows PowerShell ISE** (обычным щелчком, не «от имени
администратора»), внизу в синей консоли наберите одну строку и нажмите
Enter:

```powershell
irm https://raw.githubusercontent.com/Andrey-Sema/workflow-automation-bot/ccr-60f70972-blxpe5/tools/windows/menu.ps1 | iex
```

Откроется меню. Пункт **9** добавляет в профиль PowerShell команду `ai1c`,
после этого меню открывается одним словом `ai1c` в любом новом окне
PowerShell / ISE.

Скрипты каждый раз скачиваются свежими из репозитория — переносить код
через мессенджеры не нужно (Telegram портит отступы и спецсимволы).
Результат каждого пункта выводится в консоль между строками
`===== РЕЗУЛЬТАТ =====` и `===== КОНЕЦ =====` и сразу копируется в буфер
обмена. Скрипты ничего не сохраняют на диск.

## Пункты

| № | Скрипт | Что делает |
|---|---|---|
| 1 | `01_env_check.ps1` | Права Windows, установленная 1С, регистрация COM, доступные программы, выход в интернет |
| 2 | `02_structure.ps1` | Реквизиты и табличные части любого объекта 1С (по умолчанию `Документ.ЗаказПокупателя` — «Наряд») |
| 3 | `03_naryad_sample.ps1` | Права на «Наряд» и как заполнены последние проведённые наряды (через запросы). ФИО, телефоны, адреса и маршруты не выводятся |
| 4 | `04_app_getobject.ps1` | Загружается ли объект наряда через `V83.Application` (скрытый толстый клиент). Через `V83.COMConnector` модуль объекта наряда не компилируется, а для записи нарядов кодом нужен объект |
| 5 | `05_nomenclature_usage.ps1` | Какая номенклатура используется в проведённых нарядах за 90 дней: код, наименование, частота, разброс цен — по вкладкам Услуги / Склад / Прочие |

`lib1c.ps1` — общие функции (подключение, доступ к объектам 1С через
`InvokeMember`, сохранение результата), загружается меню автоматически.
